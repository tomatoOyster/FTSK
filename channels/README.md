# FTSK-4 独立信道配对试验

本目录测量软件接收机对采样和射频误差的敏感度。每组使用相同的 64 个载荷、噪声实现、包头位置、载波初相和回波相位。每次只向接收机提供连续 CF32 流，以输出恰好一个正确的 32 字节载荷作为成功条件。未检出包和错误载荷均计为失败。

## 采样、噪声和比较口径

- 发送端按空口频点定义生成连续时间分段单音，在 1.024 MHz 网格上求值。时段边界的相位自然连续。计算复数载波和时延后，接收端通过 Kaiser 窗低通 FIR 抽取至 128 kHz。FIR 的理想截止频率为 64 kHz，长度为 385 个过采样点，离线去除确定性群延迟。
- `phase` 是相对于名义采样周期的连续起点延迟。接收采样时钟为名义时钟乘以 `1 + ppm × 10⁻⁶`。使用同一物理波形在新时刻求值，避免对已经离散的 128 kHz 信号作线性插值所带来的频率选择性衰减。
- 单径参考幅度为 1。复白噪声在过采样域注入，按 FIR 系数平方和归一化，使抽取后的期望复噪声功率为 `10^(−SNR/10)`。报告的 −3 dB 是相对于单位参考功率的采样 SNR。滤波和选择性衰落造成的信号功率变化保留在测量里。
- 两径模型为直达与一个静态延迟副本之和，以 `sqrt(1+a²)` 归一化。`a` 表示反射径与直达径的幅度比。每个包采用独立均匀的静态回波相位，同一包在所有试验中使用相同相位。2 µs、20 µs 和 80 µs 分别约为 0.256、2.56 和 10.24 个基带采样。
- 所有场景在包头的初始频偏均为 +1200 Hz。包内瞬时频偏按 `f(t)=1200 + slope × t` 变化。IQ 失配在信号与噪声叠加之后施加，Q 路增益增加 1 dB、正交角误差 5°。DC 场景加入幅度 0.10、相位 0.7 rad 的常量，保留与期望来波的相对幅度。
- 参考 SNR、采样偏差和双径参数都是合成模型输入。具体设备和场地的发射频谱、振荡器热漂移、AGC、ADC 削顶及多径时变特性需用实测 IQ 建模。

## 配对结果

| 合成条件 | 正确接收 / 64 |
|---|---:|
| 单径基线，0.25 或 0.5 个采样周期起点偏移（三种配置各自统计） | 64 / 64 |
| +25、−50、+250、+1000 ppm 采样时钟（四种配置各自统计） | 64 / 64 |
| +3000 ppm 采样时钟 | 37 / 64 |
| 1、25、50、100 kHz/s 线性频漂 | 64、64、61、0 / 64 |
| 回波 2 µs、幅度 0.4 | 55 / 64 |
| 回波 20 µs、幅度 0.7 | 40 / 64 |
| 回波 80 µs、幅度 0.9 | 24 / 64 |
| 回波 250 µs、幅度 1 | 0 / 64 |
| DC 0.10、单独 IQ 误差、两者合用（三种配置各自统计） | 64 / 64 |
| 0.37 采样延迟、+25 ppm、1 kHz/s、2 µs 幅度 0.4 回波、DC 和 IQ 误差同时存在 | 58 / 64 |

50 kHz/s 在 35 ms 包内累积 1750 Hz 的载波变化，64 包中丢了 3 包。100 kHz/s 累积 3500 Hz，64 包全部丢失。接收机仅在包头估计一次载波频偏。四种双径配置同时改变了延迟和幅度，因此表中仅比较整组配置的表现。基线的 64/64 对应单侧 95% 的误包概率上界约 4.6%。所有配置均未观察到额外包或错误载荷输出。用头 16 个参考试验单独检查噪声，归一化后的实际平均噪声功率为 0.9990。

## 复现

在项目根目录执行以下命令。`paired.json` 包含随机种子、NumPy 版本、接收机文件 SHA-256、每种配置的成功数、相对基线新失败和新成功计数，以及第一个基线成功而配置失败的试验号。

```powershell
python channels/study.py --trials 64 --summary channels/paired.json
```

试验号 2 在基线成功，在 2 µs、幅度 0.4 回波下失败。以下命令生成两份各 49,152 字节的原始 IQ，并使用独立的命令行解码入口复核。回放路径须为新文件。

```powershell
python channels/study.py --index 2 --cases base --replay base.cf32
python channels/study.py --index 2 --cases echo2 --replay echo.cf32
python modem.py decode base.cf32
python modem.py decode echo.cf32
```

已在 NumPy 2.3.5 上核对结果。第一份在第 611 个采样位置解出 `5b895de26993bd85a423fdd535e07ed789ca5b275d644dad4ac79227a7e488fb`，估计频偏为 +1199.22 Hz。第二份无 CRC 通过的输出。对应 CF32 SHA-256 依次为 `45c24e313ba925a8c3f95ec0495cc8b2333719dcd746ae1ca78c2b9632ec557b` 和 `a4302838381ed4f3990d64d773ab3e06e8f067c5bb8c38c1c220f23307949444`。
